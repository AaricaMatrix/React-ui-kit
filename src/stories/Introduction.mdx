## Install

```bash
pnpm add @aaru/ui-kit
```

```tsx

import '@aaru/ui-kit/styles.css';

function App() {
  return (
    <Card title="Welcome">
      <Button variant="primary">Get started</Button>
    </Card>
  );
}
```

## Why this exists

Most projects rebuild the same handful of UI primitives from scratch, with inconsistent
accessibility and no shared test coverage. This library centralizes them once, tested and
documented, so they're reused instead of reimplemented.

Every interactive component here is keyboard accessible: focus trapping in the modal, arrow-key
navigation in tabs, and proper `aria-invalid`/`aria-describedby` wiring on every form input.

Browse the components in the sidebar to see every variant, state, and interaction live.
